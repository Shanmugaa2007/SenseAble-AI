# SenseAble AI

> AI doesn't ask the person to adapt to technology. The technology adapts to the person.

SenseAble AI is an AI-powered Universal Accessibility Assistant designed to make smartphones more accessible for people with visual, hearing, speech, mobility, and multiple disabilities.

## Live Prototype

🔗 https://hall-zebra-89727725.figma.site/

## The Problem

Millions of people with disabilities use different accessibility tools for different needs. Switching between multiple apps makes everyday tasks slower and more difficult.

## Our Solution

SenseAble AI combines multiple accessibility features into a single intelligent assistant that adapts to each user's needs.

## Features

- 👁️ Object Detection with Voice Guidance
- 🚶 Navigation Assistance
- 🦻 Real-time Speech to Text
- 🤟 Sign Language Understanding
- 🗣️ Text to Speech
- 🎤 Voice-first Interaction
- 📍 Emergency SOS with Location
- 🔒 Privacy-focused AI

## Accessibility Modes

- Blind / Low Vision
- Deaf / Hard of Hearing
- Non-speaking
- Mobility Assistance
- Multiple Disabilities
